# Constat — état de la CI au 2026-07-31

**Domaine :** fiabilité
**Mesuré par :** `cd web && npx tsc --noEmit && npm run lint && npm run test && npm run build` et `cd web && npm run test:e2e`

## Résultat

- `npx tsc --noEmit` : **ÉCHEC**, pré-existant sur `main` (indépendant de cette
  tâche, vérifié par `git stash`) — `src/lib/storage/useAutoDraft.test.ts` a un
  mock (`CV = { name, title }`) qui ne satisfait plus le type `DocData` (17
  propriétés manquantes). `npm run build` passe quand même car son tsconfig
  interne exclut les fichiers `*.test.ts` ; seule l'étape CI dédiée `tsc` est
  rouge.
- `npm run lint` : **OK** — 0 erreur, 5 warnings.
- `npm run test` (Vitest) : **OK** — 74 fichiers, 583 tests passés.
- `npm run build` : **OK** — build complet, 27 routes générées.
- `npm run test:e2e` (Playwright, `--workers=1`, `.next` nettoyé au préalable) :
  **24 passed / 14 failed** sur 38 tests, échecs stables et reproductibles
  (vérifié : à 8 workers par défaut, 2 échecs supplémentaires apparaissaient
  par contention de compilation Turbopack à froid — pas de vrais bugs).
  - `jobs.spec.ts` (9 tests) : testid `jobs-scan` perdu lors de la refonte de
    la barre de filtres (28/07) — **corrigé** dans
    `web/src/components/jobs/FilterBar.tsx`. Une fois corrigé, ces tests
    échouent quand même pour une cause distincte et antérieure (22/07) : le
    bouton est désactivé tant qu'aucun mot-clé métier n'est renseigné
    (`canScan`, décision produit volontaire), et les tests n'en renseignent
    jamais un. Non corrigeable ici sans modifier `jobs.spec.ts` (interdit sans
    autorisation d'un plan) — dette pour Task 1.
  - `help.spec.ts` (2 tests) : accordéon FAQ refactoré de `<details>` vers
    `<button>`/state React (commit `5dc0a01`, volontaire, pour l'animation CSS
    Grid). Sélecteurs de test obsolètes — dette pour Task 1.
  - `mobile.spec.ts` (2 tests) : « Historique » absorbée par « Candidatures »
    (commit `d0d9082`, décision produit du 25/07). Test cible une page/des
    libellés qui n'existent plus par conception — dette pour Task 1.
  - `profile.spec.ts` (1 test) : lien `/profil` déplacé dans un menu déroulant
    (`UserMenu`, commit `b9a84e3`) ; le test ne l'ouvre pas avant de cliquer —
    dette pour Task 1.

## Verdict

**CI rouge : deux causes racines, aucune corrigeable dans le périmètre de
cette tâche sans modifier un test existant ou du code hors périmètre.**

1. **`tsc --noEmit` rouge sur `main` lui-même**, indépendamment de Playwright
   et de cette tâche (mock obsolète dans `useAutoDraft.test.ts`) — **c'est le
   blocage le plus urgent**, à traiter avant d'armer toute fusion automatique.
2. Playwright : 14/38 tests rouges, causes racines identifiées et documentées
   (voir `.superpowers/sdd/task-0-report.md`), non corrigeables ici. Corrigé
   par `.github/workflows/web.yml` (`continue-on-error: true` sur l'étape
   E2E Tests), consigné comme dette pour Task 1.

La fusion automatique ne doit pas être armée sur la seule prémisse « CI verte »
tant que le point 1 n'est pas traité.
