# Journal — Éclaireur, 2026-08-07 (deuxième réveil de l'Éclaireur ce jour)

## Domaine

Cohérence visuelle — premier passage de la boucle sur ce domaine (rotation
`boucle/roles/eclaireur.md`). Ce n'est pas un des quatre domaines détaillés
dans le mandat (« manques fonctionnels », « coût des appels externes »,
« hygiène du dépôt », « briques externes ») : j'ai appliqué la règle générale
(« aucun constat sans chiffre ni reproduction ») et le format standard.

## Périmètre lu

Uniquement `web/src/app/globals.css` (2896 lignes, feuille de style unique du
produit) et, pour vérifier chaque sélecteur en contexte, le composant qui
l'appelle (`AtsPanel.tsx`). Pas d'autre fichier du dépôt lu.

## Démarche

1. Grep systématique sur les propriétés dimensionnelles (`border-radius`,
   `font-size`, `padding`, `gap`) pour compter les valeurs distinctes et
   vérifier l'absence de variables CSS correspondantes — même méthode que
   pour les couleurs (déjà tokenisées, ~35 variables) mais appliquée aux
   dimensions, jamais faite par la boucle jusqu'ici.
2. Repéré `.ats-mid { background: #f5a623 }` comme anomalie en comparant les
   trois états d'un même composant (`ats-ok`/`ats-mid`/`ats-low`) : deux
   utilisent des tokens redéfinis par thème, un est figé. Chiffré l'écart par
   un script Node inline (luminance relative WCAG) plutôt que d'estimer à
   l'œil.
3. Repéré la duplication du bouton CTA orange en cherchant tous les
   sélecteurs qui posent `var(--cta-grad)` et en croisant avec `--on-orange`
   (jeton déjà connu de la boucle via l'idée n°6, contraste du texte) — ce
   sous-constat explique une idée déjà classée plutôt que de la redoubler.
4. Comparaison concurrentielle : tenté de télécharger le CSS de production
   des huit produits de référence (`curl` direct, sans exécuter leur JS).
   Réussi pour Rezi seul (Webflow, CSS statique servi par CDN) — décompté ses
   `border-radius` avec la même méthode que pour CVMatchr, chiffre contre
   chiffre. Jobscan et Simplify bloquent le robot (HTTP 403), Careerflow
   redirige sans contenu, Enhancv et Huntr ne servent pas de CSS statique
   (probablement injecté par JS) — signalé tel quel plutôt qu'ignoré ou
   deviné. Kickresume : page HTML récupérée mais pas de CSS compilé
   trouvable ; description qualitative obtenue par lecture de la page,
   explicitement marquée comme un signal plus faible qu'une mesure.

## Décisions et raisons

- N'ai pas proposé de chantier séparé pour les `padding`/`gap` en dur (23 et
  17 valeurs distinctes respectivement) : même cause racine que les rayons et
  les tailles de texte (absence de tokens de dimension), les mentionner comme
  corroboration dans le constat plutôt que comme un cinquième chantier évite
  de faire noter quatre fois la même chose à l'Arbitre sous des angles
  différents.
- Le sous-constat sur la duplication du bouton CTA (`var(--cta-grad)` dans
  ~13 blocs séparés) recoupe l'idée n°6 déjà classée dans `IDEES.md` (le
  texte blanc sur ce bouton plutôt que le jeton `--on-orange`). Je ne l'ai pas
  proposé comme une idée strictement nouvelle et indépendante : je l'ai écrit
  comme un complément explicatif, en le signalant explicitement dans
  `IDEES.md`, pour que l'Arbitre juge lui-même s'il le rattache à l'idée n°6
  ou le note à part — plutôt que de trancher moi-même une question de
  classement qui ne m'appartient pas.
- Comparaison concurrentielle limitée à une seule mesure chiffrée (Rezi) faute
  d'accès au CSS des sept autres produits de référence — signalé chaque échec
  d'accès avec son code HTTP plutôt que de généraliser à partir d'un seul
  point de données ou d'inventer une comparaison.
